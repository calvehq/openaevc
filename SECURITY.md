# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private vulnerability reporting ("Report a vulnerability" on the Security tab of this repository).

We acknowledge reports within 3 business days, agree on a disclosure timeline (default 90 days), and credit reporters who wish to be credited.

## Scope

In scope: the protocol specification, reference runtime, `openaevcd`, the extension host, SDKs and conformance suite. The threat model is `spec/security-model.md`.

## Supported versions

Pre-1.0: only the latest minor release receives security fixes.
