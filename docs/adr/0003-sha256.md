# 0003. SHA-256 as the mandatory digest

- Status: accepted
- Date: 2026-09-26

## Decision

Protocol 0.1 uses SHA-256 exclusively, written `sha256:<hex>`. The algorithm tag is part of the text form so a later protocol can add algorithms without reinterpreting stored objects.

## Consequences

Universally available in every target language's standard library (Node, Python, Go).
