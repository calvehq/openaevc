# 0004. Ed25519 signatures with domain separation

- Status: accepted
- Date: 2026-09-26

## Decision

All principals authenticate with Ed25519 keys. Signed messages are prefixed with `"OPENAEVC/1 <domain>\n"` (`request`, `grant`, `object`, `checkpoint`, `receipt`) so signatures cannot be replayed across purposes. Verification is strict (`verify_strict`). Keys are supplied through a `Signer` trait so deployments can use HSMs or OS key stores.

## Consequences

Deterministic signatures make cross-SDK signature fixtures reproducible. Node and Go have native Ed25519; the Python SDK ships a small pure-Python RFC 8032 implementation to stay dependency-free.
